# Выпуск SDK 2.0.2

Версии пакета, нативных зависимостей и runtime metadata должны совпадать.
Инструкции установки и настройки приложения находятся в README.md;
изменения интеграции звонков — в docs/MIGRATION_2.md.

1. Выполните полный набор нативных тестов и проверьте оба podspec: PushPlatformSDK и PushPlatformExtension версии 2.0.2.
2. Зафиксируйте проверенные исходники и создайте git-тег `v2.0.2` на этом коммите.
3. Swift Package Manager и CocoaPods должны разрешать оба продукта из одного тега.
4. Workflow `ios-sdk-release` запускается вручную; публикация CocoaPods управляется его параметром `publish`.
